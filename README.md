# 儿童摄影特色版工作台

儿童摄影特色版生成与编辑工作台，提供接近桌面应用的 PWA 界面、参考款式生成、图片局部编辑，以及参考图迁移。

## 主要功能

- **特色版排版**：上传孩子照片并选择参考款式，生成横向儿童摄影特色版。
- **参考图迁移**：上传人物原图和一张服装/造型/背景参考图，可分别勾选服装、造型、光影、背景迁移。第一张孩子照片作为原图，其余照片只辅助保持身份。
- **局部编辑**：在生成结果上涂选区域并描述修改要求。
- **PWA**：通过 HTTPS 或 localhost 使用，可安装到桌面或程序坞。

## 本地运行

运行 `bash scripts/build.sh` 生成 `dist/` 静态站点目录，再通过 HTTPS 或 localhost 提供静态文件。

AI 服务的 Base URL、Key 和模型配置由使用者在浏览器中填写；图片由浏览器直接发送到所配置的服务。

## 参考图片

为了保护儿童肖像隐私，80 张参考版图片没有上传到本仓库。特色版排版中的图库需要在本地 `ui/refs/` 放入 `01.jpg` 至 `80.jpg` 后才能完整使用。参考图迁移模式可直接上传自己的参考图片。请勿在未获授权时把儿童照片提交到 GitHub。

API Key 不应提交到仓库。
