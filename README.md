# 儿童摄影特色版工作台

儿童摄影特色版生成与编辑工作台，提供接近桌面应用的 PWA 界面、特色版排版、图片局部编辑，以及集成在排版流程中的参考图迁移。

## 主要功能

- **特色版排版**：上传孩子照片并选择版面参考款式，生成横向儿童摄影特色版。
- **参考图迁移**：在同一个特色版排版流程中，可选上传服装、造型、光影或背景参考图，并勾选要迁移的项目。版面仍由所选款式参考图决定；迁移参考图只影响勾选项目，无需切换工作模式。
- **局部编辑**：在生成结果上涂选区域并描述修改要求。
- **PWA**：通过 HTTPS 或 localhost 使用，可安装到桌面或程序坞。

## 本地运行

运行 `bash scripts/build.sh` 生成 `dist/` 静态站点目录，再通过 HTTPS 或 localhost 提供静态文件。

AI 服务的 Base URL、Key 和模型配置由使用者在浏览器中填写；图片由浏览器直接发送到所配置的服务。

## 参考图片与隐私

为了保护儿童肖像隐私，80 张特色版参考图没有上传到本仓库。需要在本地 `ui/refs/` 放入 `01.jpg` 至 `80.jpg` 后，版式图库才能完整使用。请勿在未获授权时把儿童照片提交到 GitHub。

API Key 不应提交到仓库。
